# Chrome Web Store 掲載文面

## 拡張機能名

Chatwork 全員に返信

## 1行要約

Chatwork の投稿アクションに「全員に返信」を追加し、投稿者と To 宛先をまとめて返信欄へ挿入します。

## 詳細説明

Chatwork の各メッセージに「全員に返信」を追加する拡張機能です。

通常の返信タグを先頭に入れたうえで、元投稿の To 宛先と投稿者をまとめて返信欄へ整形して挿入します。

### 主な機能

- 元投稿の To 宛先を抽出
- 投稿者を返信対象に追加
- 自分自身の accountId を除外
- 重複する宛先を除外
- Chatwork 標準の返信タグ形式をそのまま利用

### 使い方

1. 拡張機能のオプション画面で自分の Chatwork accountId を設定
2. Chatwork の投稿にマウスを載せる
3. アクション列に表示される「全員に返信」をクリック
4. 返信欄に返信タグと To 宛先が挿入されることを確認して送信

### 注意事項

- 返信文の送信は自動では行いません。送信はユーザーが確認して実行します
- Chatwork の画面構造変更により調整が必要になる場合があります
