# Chatwork Assist Privacy Policy

- 制定日: 2026-08-30
- 更新日: 2026-10-07（0.5.0の記号入力・任意のGeminiリライト・保存時保護を追記）
- 対象: Chrome 拡張機能 `Chatwork Assist`

0.5.0からAIリライトと保存時の透過暗号化を追加します。更新日時点で0.5.0は公開準備中です。0.4.1以前にはAIリライトがなく、ルームメモは暗号化せず保存されます。利用中のバージョンはChromeの拡張機能管理画面で確認できます。

## 1. 適用範囲と公式性

この方針は、Chatwork（`www.chatwork.com`）上で動作する `Chatwork Assist` に適用します。本拡張は Chatwork運営とは無関係・未公認の非公式拡張です。既存公開版「Chatwork 全員に返信」とは別の拡張機能であり、旧版のプライバシーポリシーをこの文書で置き換えるものではありません。

## 2. 単一目的と利用目的

単一目的は、Chatwork のメッセージ作成・操作と、ルームごとのメモ管理を補助することです。全員に返信、ダブルクリック・ワンクリックリアクション、一括既読、ルームメモ、記号入力、任意のAIリライトで、次の情報を必要な範囲で扱います。

| 扱う情報 | 利用目的 |
| --- | --- |
| Chatwork ページで現在表示されているメッセージ構造、`To` 宛先、投稿者情報 | 返信タグ・宛先の生成、メッセージ操作対象の特定 |
| Chatwork のルーム ID・ルーム名・未読件数・最新チャット ID | 未読ルームの表示と、利用者が実行した一括既読 |
| Chatwork ページ内のログインセッション情報 `ACCESS_TOKEN`、`MYID`、クライアントバージョン | 一括既読時に Chatwork の同一 origin 内部エンドポイントを呼び出すため。一時的に参照し、拡張の保存領域へ保存しない |
| 利用者が設定した `selfAccountId`、機能の ON/OFF、リアクション、ヒント表示、メモのパレット | 拡張の動作設定 |
| 利用者が入力したルームメモ（ルーム ID・ルーム名、タイトル、本文、色、位置、サイズ等） | ルームメモの表示・編集・一覧・検索・CSV 入出力 |
| 利用者が明示的に選択した CSV ファイル | ルームメモのローカルインポート |
| 入力欄の下書きと選択範囲 | 記号の挿入・選択文の囲み、AI候補の作成と明示採用 |
| 利用者が設定したGemini APIキー、任意の文体例3例、AI利用条件の確認状態 | API認証、丁寧モードでの文体参照、利用条件の確認 |
| 利用者が「生成」を押した下書きと、丁寧モードの文体例、Googleが返した候補 | Google Geminiによる文章のリライトと原文比較。採用前の内容確認 |

メッセージ送信は自動で行いません。返信機能は返信欄への入力までで、送信は利用者の操作です。リアクションと既読化は、利用者の操作に応じて Chatwork に反映されます。ルームメモを Chatwork のメッセージとして投稿する処理はありません。

ダブルクリックリアクションが有効な間は、リアクション対象を判定するためにクリック、マウス位置、対象要素を端末内で一時的に処理します。ルームメモの移動・リサイズでもポインタ位置を一時的に処理し、操作完了後のメモ位置・サイズだけを保存します。生のクリック履歴・マウス移動履歴は保存せず、開発者が管理するサーバーへ送信しません。

## 3. 保存場所と保存形式

### 設定

設定キー `chatworkAssistSettings` は `chrome.storage.sync` に保存します。Chrome の同期を利用している場合、Chrome の同期機能（Google 経由）で設定が扱われることがあります。開発者がこの同期データを受け取る独自サーバーは用意していません。

### ルームメモ

0.5.0以降のルームメモは、メモ内容をAES-GCMで暗号化し、`chrome.storage.local` にメモ単位のレコードとして保存します。保存キーには対応ドメイン `www.chatwork.com` と `roomId`・メモIDが含まれますが、Chatwork アカウント ID には紐付けません。拡張のバックグラウンド起動時に、未訪問ルームを含む旧版の平文メモの暗号化移行を試みます。読み込み時にも未移行データを移行します。移行や復号に失敗した場合に元データを削除したり、平文保存へ切り替えたりはせず、移行は次のバックグラウンド起動時にも試みます。

メモ機能を OFF にしても保存済みメモは残り、オプション画面の一覧・検索・CSV 入出力は利用できます。OFF は削除ではありません。各ルームの付箋での個別削除は対象のメモを削除します。拡張の保存領域やプロファイルの消去、アンインストールではメモが失われ、拡張から自動復元はできません。通常の閲覧履歴・キャッシュ削除はメモ削除の手順ではありません。新しい拡張機能 ID への自動移行は行いません。CSVをエクスポートし、移行先で件数・本文を確認してから移行元の削除を検討してください。CSV非対応の旧 ZIP では、先にエクスポートを可能にする別手順が必要です。

### CSV

CSV のインポートは、利用者がファイル選択した後に `FileReader` またはファイルの読み取り機能でローカルに読み込みます。エクスポートは保存済みメモからローカルの `Blob` を作り、利用者のブラウザへダウンロードします。CSV を開発者サーバーへアップロードする処理はありません。CSV のタイトル、本文、ルーム名、ルーム ID、日時、配置情報などはプレーンテキストとして含まれるため、バックアップファイルの保管と共有は利用者が管理してください。

### AI設定と暗号化鍵

Gemini APIキー・文体例・AI利用条件の確認状態は、拡張機能専用のIndexedDBへ暗号化して保存し、Chrome同期には保存しません。保存済みAPIキーをChatworkページやcontent scriptへ返す仕組みはありません。オプション画面には設定済みかどうかを表示し、キー変更時は再入力します。

AES-GCMの鍵は、同じChromeプロファイル内の拡張専用IndexedDBに、WebCryptoの非抽出鍵として保存します。パスワード入力やロック解除は不要です。この方式は保存レコードの平文表示を避けるためのものであり、端末の侵害、同じプロファイルを操作できる第三者、悪意のある拡張による実行まで防ぐ金庫を保証しません。鍵やプロファイルが失われると暗号文を復号できません。移行前の旧データや端末バックアップの完全な消去も保証しません。

AIの原文・候補は生成・比較・短いUndoに必要な間、メモリと画面上で扱います。拡張独自の会話履歴として永続保存しません。原文や採用した文章をChatworkの下書き欄へ表示した後のページ側の扱いは、Chatworkの仕様と条件に従います。

## 4. Chatwork との通信

ワンクリックリアクションは、利用者が押したメッセージの標準リアクション操作をクリックして付与・取り消しを行います。アイコン表示にはChatwork画面上の標準画像URL、または初回表示用の同じ標準画像の固定URLを参照し、`https://assets.chatwork.com/images/emoticon2x/` 内の対象6種類の画像だけを利用します。画像そのものを拡張へ同梱せず、参照先へメッセージ本文・メモ・ルーム情報を付加しません。追加する画像要素は `referrerPolicy: no-referrer` とし、ページURLをRefererとして送信しません。画像の読み込みに失敗した場合は日本語名で表示します。外部JavaScriptを読み込む機能ではありません。

一括既読機能を利用者が実行したとき、ページ内の `RL.rooms` と `room.load` から未読ルームと最新チャット ID を確認し、ログイン中の `ACCESS_TOKEN` を使って `https://www.chatwork.com/gateway.php?cmd=read`（ページと同一 origin）へ `credentials: same-origin` のリクエストを行います。これは Chatwork のログインセッションを使う内部処理であり、公式公開 API トークンを利用者に入力させるものではありません。Chatwork 側の仕様変更により、この機能が利用できなくなる場合があります。

上記の Chatwork への操作・リクエストと、開発者が管理するサーバーへの送信は区別されます。本拡張には、開発者サーバーへの送信、アクセス解析、広告・トラッキング、ユーザーデータの販売を目的とする処理はありません。Chrome の同期を有効にした場合の Chrome/Google の取り扱いは、Chrome/Google のサービス条件とプライバシー設定に従います。

## 5. Google Geminiとの通信

AIリライトは初期状態でOFFです。利用には、利用者自身が用意した、有効なCloud Billingアカウントに紐づくGoogle CloudプロジェクトのGemini APIキーと、利用条件の明示確認が必要です。拡張はキーだけから課金設定を技術的に検証できないため、確認は利用者の自己申告です。Googleへの利用料金が発生する可能性があります。本拡張の開発者がAPI利用料を立て替えたり請求したりする仕組みはありません。

利用者が送信前の原文を確認して「生成」を押したときだけ、`https://generativelanguage.googleapis.com/` の固定エンドポイントへHTTPSで送信します。送信するのは下書き、選択モード、リライト指示と、丁寧モードで保存した任意の文体例です。下書きに含まれる氏名・宛先ID・URL・返信タグ等もそのまま送信対象になり得ます。APIキーはGoogleへの認証ヘッダーに使用します。Chatworkのログインセッション情報、ルームメモ、CSV、会話履歴全体を自動で送信する処理はありません。モードを選ぶだけでは送信しません。開発者サーバーを経由しません。

[Gemini API追加利用規約](https://ai.google.dev/gemini-api/terms)によると、有料サービスではプロンプトと応答はGoogleの製品改善に使用されません。ただし、安全・不正利用検出や法令対応のための限定的なログ保持があります。本拡張はGoogle側の保存ゼロや人による閲覧ゼロを保証しません。APIのプロジェクトログを無効にする指定は、これらの扱いを撤回するものではありません。

無料枠は入力・出力がGoogleの製品改善や人手レビューに利用され得るため、本拡張の公開版AIの利用対象外です。送信する権限のない機密情報・個人情報・センシティブな情報は含めず、送信する権限のある文章だけを使用してください。Gemini APIは18歳以上の業務・開発用途とGoogleの[提供地域](https://ai.google.dev/gemini-api/docs/available-regions)等の条件に従って利用してください。

## 6. ページ上の表示と限界

ルームメモ・AIの原文と候補は通常の Chatwork ページの `input` / `textarea` 等のDOM要素として表示されます。そのため、Chatworkページ内のスクリプトや、ページへアクセスできる別の拡張が表示内容を読み取れないこと、完全に非共有であること、誰にも見られないことは保証しません。保存時の暗号化は表示中の情報の隔離とは異なります。Chromeプロファイルや端末へのアクセスを保護してください。

## 7. 利用者による管理

利用者は、オプション画面で各機能を OFF にし、各ルームに表示する付箋からメモを個別削除し、オプション画面から CSV をエクスポートしてバックアップできます。一覧は閲覧専用で、OFF ではメモは削除されません。別の拡張機能 ID へ移る場合は、CSV書き出し → 移行元の無効化 → Chatwork再読み込み → 移行先で取り込み・件数と本文確認の順で行い、確認前に移行元をアンインストールしないでください。

AI設定では保存済みAPIキーを削除できます。文体例は各欄を空にしてAI設定を保存すると削除できます。AIをOFFにするだけではキーや例は削除されません。拡張の保存領域やプロファイルの消去・アンインストールでローカル設定と暗号化鍵は失われます。Googleへ送った内容の扱いと削除はGoogleの規約・設定に従い、本拡張からGoogle側の保持データを削除する機能はありません。

## 8. Limited Use と第三者提供

本拡張が扱うユーザーデータは、第2節の単一目的と利用者向け機能を提供するために必要な範囲でのみ使用します。開発者は、ユーザーデータを販売せず、広告、アクセス解析、トラッキング、信用力判断、融資、または本拡張の機能と無関係な目的に使用・転送しません。

第三者への通信は、Chatworkの操作に必要な通信・標準画像の取得、Chrome同期が有効な場合の設定同期、および利用者が明示実行したGoogle Geminiでのリライトに限定します。リライトのGoogleへの提供は、文章を整える利用者向け機能に必要な範囲です。Googleの有料API条件に従い、製品改善を目的とする無料枠を利用対象にしません。開発者は、機能と無関係な転送、広告利用、一般的なAIモデルの学習を目的とする利用を行いません。

開発者が管理するユーザーデータ保存サーバーはなく、開発者やその担当者が保存済みメモ・Chatworkメッセージ・APIキー・文体例を閲覧する仕組みもありません。Google等のサービス提供者による必要な安全・不正利用調査、法令遵守等の扱いは各サービスの条件に従います。利用者向け機能、必要なセキュリティ対応、適用法令に従う範囲を除いてユーザーデータを使用・転送しません。
